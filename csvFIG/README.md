# csvFIG

箱线图、柱状误差图、小提琴图和项目保存；默认无图例。

从仓库根目录启动：

```powershell
python csvFIG/csvFIG.py
```

也可以进入本目录执行 `python csvFIG.py`。请保留同级的 `../common/` 共享模块。

实验数据：[examples/experiment_distributions.csv](examples/experiment_distributions.csv)。手动保存的项目放入 `examples/projects/`。

完整功能、安装方法与界面截图见[主 README](../README.md)。
